# Python-Practice 🐍

> This is how I practiced my Python! A collection of scripts, coding challenges, and daily exercises documenting my Python learning journey.

---

## 📂 Repository Structure

The repository contains a variety of scripts covering fundamental concepts, problem-solving, and data structures:

*   **Core Concepts:** Fundamentals like loops (`for`, `while`), functions, dictionaries, tuples, lists, 2D lists, and error handling.
*   **Dojo Exercises & Daily Practice:** Hands-on logical problem-solving scripts (`dojo1.py` through `dojo5.py`, `daily questions.py`).
*   **Algorithms & Problem Solving:** Solutions to coding challenges including missing numbers, sorting/finding largest elements, string reversal, and LeetCode problems.

---

## 🚀 Topics Covered

* Python 3
* Data Structures & Algorithms (DSA)
* Control Flow & Functions
* Problem Solving & Logic Building

## 🛠️ Usage

Feel free to browse, explore, or run any of the `.py` files to see different implementations of Python concepts and algorithms!
